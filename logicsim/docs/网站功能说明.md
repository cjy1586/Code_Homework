# LogicSim 网站功能说明文档

> 基于原版 https://kuangdash.gitlab.io/logicsim（2021 年）源码分析整理

## 一、网站定位

LogicSim 是一个**纯前端（静态）逻辑表达式可视化工具**。用户在文本框中输入「逆波兰（后缀）逻辑表达式」，系统将其解析为逻辑电路/判定图（BDD, Binary Decision Diagram，二元决策图），并以可交互的图形方式渲染出来。

## 二、核心业务功能

### 1. 逻辑表达式解析（LogicParser）

支持输入**逆波兰逻辑表达式**，支持五种二元/一元逻辑操作符：

| 操作符 | 名称 | 逆波兰示例 | 含义 |
|--------|------|------------|------|
| `.` | 逻辑与 AND | `a b .` | a ∧ b |
| `,` | 逻辑或 OR | `a b ,` | a ∨ b |
| `<` | 逻辑非 NOT | `a <` | ¬a |
| `>` | 逻辑推出 IMPLY | `a b >` | a → b |
| `=` | 逻辑等价/同或 EQUAL | `a b =` | a ↔ b |

- 变量名可以是任意字符串（如 `a`、`fe`、`ge`），各 token 之间以空格分隔。
- 解析过程将表达式构造成一个「条件树」（Shannon 展开结构）：节点 `{S, "0", "1"}`，表示「若 S 成立则走 1 分支，否则走 0 分支」。
- 解析错误时返回字符串提示（如空串、格式错误、参数数量错误等）。

### 2. 真值表/判定图模型生成（ModelGen）

将条件树转换为「真值表 + 变量序」结构：

- `value`：满足表达式为真的所有赋值行（minterm），每行的 `.` 字段表示结果真假。
- `order`：表达式中出现的变量列表（变量序）。

### 3. 图模型生成（ViewGen）

将 ModelGen 的结果转换为 JointJS 图数据模型（`nodeArray` + `linkArray`），节点类型包括：

| 节点类型 | 含义 |
|----------|------|
| `0` / `1` | 常量 0 / 常量 1（逻辑假/真） |
| `Import` | 输入变量节点 |
| `Export` | 输出节点（Out） |
| `SEL` | 选择器/多路复用器节点（对应 BDD 的分支决策点） |

### 4. 交互式图形渲染（ViewGen.js + JointJS）

- **渲染**：使用 JointJS 在画布上绘制节点与连线，自动布局（LR 方向）。
- **画布操作**：
  - 拖拽空白区域平移画布；
  - 鼠标滚轮 / Alt+↑↓ 缩放；
  - 右下角迷你地图（mini-map）导航定位；
  - 双击空白取消高亮。
- **元素编辑**：
  - 单击节点/连线高亮并显示关联连接；
  - 悬停出现删除/边界工具；
  - 右侧面板可修改元素名称、备注。
- **文本/文件互转**：
  - 「解析文本」：逆波兰表达式 → JSON 图模型；
  - 「文本转图」：JSON 图模型 → 图形；
  - 「图转文本」：图形 → JSON 图模型；
  - 「载入文本 / 保存文本」：本地文件导入 / 导出 JSON。

## 三、技术栈

| 层 | 技术 |
|----|------|
| 页面结构 | HTML5 + W3.CSS（原版） |
| 样式 | style.css + joint.css + select2.css |
| 图形引擎 | JointJS（依赖 jQuery、Lodash、Backbone、Graphlib、Dagre） |
| 下拉选择 | Select2 |
| 解析逻辑 | 手写递归下降/后缀解析（LogicParser.js） |
| 部署方式 | 纯静态站点（GitLab Pages） |

## 四、典型使用流程

1. 在「逆波兰逻辑表达式」文本框输入表达式，例如 `a b . fe >`；
2. 点击「解析文本」→ 下方 JSON 文本框生成图模型；
3. 点击「文本转图」→ 画布渲染出逻辑判定图；
4. 可通过迷你地图导航、缩放，点击元素查看/修改名称备注；
5. 「保存文本」可将 JSON 模型导出到本地文件。
