# LogicSim 改造说明

> 针对原版 https://kuangdash.gitlab.io/logicsim（2021 年）进行的升级改造

## 一、改造需求

1. 给逻辑表达式增加**量词**支持；
2. 升级页面 UI 为**现代化组件**。

## 二、改造内容

### 1. 逻辑量词支持（LogicParser.js）

新增两个量词操作符，采用逆波兰后缀语法：`E x ∀` / `E x ∃`（先写公式 E，再写被量化的变量 x，最后写量词）。

| 量词 | 逆波兰写法 | 数学含义 | 实现语义 |
|------|-----------|----------|----------|
| ∀ 全称量词 | `E x ∀` | ∀x.E | E[x:=0] ∧ E[x:=1] |
| ∃ 存在量词 | `E x ∃` | ∃x.E | E[x:=0] ∨ E[x:=1] |

**实现方式**：
- 新增 `restrict(node, variable, value)`：把判定树中的变量替换为常量 0/1（Shannon 代入）；
- 新增 `forallM` / `existsM`：基于 `restrict` + 已有的 `andM` / `orM` 组合实现；
- 扩展解析器 token 切分与分支，支持 `∀`、`∃`，并增加错误校验（缺少变量名、量词参数非变量名时报错）。

**验证用例（已通过）**：
| 表达式 | 结果 |
|--------|------|
| `a b , a ∃` | 恒真（∃a.(a∨b) ≡ 1） |
| `a b , a ∀` | 等于 b（∀a.(a∨b) ≡ b） |
| `a b . a ∀` | 恒假（∀a.(a∧b) ≡ 0） |
| `a b . a ∃` | 等于 b（∃a.(a∧b) ≡ b） |

### 2. UI 现代化（index.html + style.css + ViewGen.js）

- **整体视觉**：采用现代化配色（靛蓝主色 #6366f1）、系统字体栈、卡片化布局、圆角 + 阴影、统一间距。
- **顶部工具栏**：
  - 新增渐变品牌区（Logo + 标题 + 副标题）；
  - 迷你地图加「画布总览」标签；
  - 输入区拆分为两张卡片：`逆波兰表达式` / `图模型 JSON`。
- **操作符快捷按钮**：新增 7 个胶囊按钮（∧ ∨ ¬ → ↔ ∀ ∃），点击即在光标处插入对应操作符，量词按钮单独高亮。
- **示例按钮**：一键填充并解析示例（含量词示例）。
- **右侧属性面板**：元素名称/备注/元素列表、操作符说明表（含量词语义说明），现代化表单样式。
- **状态栏**：带状态圆点的底部状态栏（成功绿 / 错误红）。
- **节点配色**：JointJS 判定图节点配色升级为现代色板（常量 0=橙、1=绿、变量=靛蓝、输出=紫、选择器=天蓝）。
- **移除冗余依赖**：去掉 W3.CSS 与 Select2（搜索框改为原生下拉）。

## 四、验证方式

- `node --check` 语法校验通过；
- Node 端到端测试：`LogicParser → ModelGen → ViewGen` 输出正确；
- Chrome 无头浏览器 + CDP 真实页面测试：解析量词表达式、文本转图均正常，无 JS 报错。
